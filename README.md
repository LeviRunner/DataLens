# O que é o DataLens: um sistema de análise de dados configurável que gera o "perfil" automático de qualquer fonte (CSV, Excel, SQL, API) sem precisar alterar o código.

* **Problema resolvido:** reuso em qualquer dado/banco/planilha.

* **Tecnologias utilizadas:** Python, pandas, Streamlit, SQLAlchemy, requests, plotly.

* **Como usar:** instruções sobre como configurar a fonte, ajustar o mapeamento ou abrir o app.

* **Links e Mídias:** link do app público no Streamlit Community Cloud, além de screenshots/GIFs.

* **Exemplos de uso:** utilizando datasets de finanças (ações B3 e EUA, cripto, finanças pessoais).
